# Movie Watchlist App

A simple and interactive Movie Watchlist application built with React. The app allows users to manage their movie collection, keep track of watched movies, and easily find movies using search and genre filters.

## Features

- **View Movies:** Display a collection of movies with their titles, genres, release years, and watched status.
- **Search Movies:** Search for movies by title.
- **Filter by Genre:** Filter movies by genre, including Action, Sci-Fi, Romance, and Horror.
- **Add Movies:** Add new movies to your watchlist.
- **Track Watched Status:** Mark movies as watched or not watched.
- **Responsive Design:** Styled using Bootstrap for a clean and responsive layout.

## Technologies Used

- React.js
- JavaScript 
- Bootstrap 5
- CSS3


## Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/newmorin2/Movie-Watchlist
   ```

2. Navigate into the project directory:

   ```bash
   cd movie-watchlist
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL provided by Vite in your browser.
